# Gelieferte Abbildungen

Hier liegen die von Illustratoren gelieferten SVG-Dateien. Vorgaben, Lieferweg und Abnahme: [docs/abbildungen/LASTENHEFT.md](../docs/abbildungen/LASTENHEFT.md).

```
abbildungen/
  koerper.svg          Abb. 1 – Körperschema (eines für alle Supplemente)
  zelle/<id>.svg       Abb. 2 – Zellabbildung je Supplement
```

Fehlt eine Datei, nutzt die Seite die eingebaute Zeichnung. Prüfen mit `npm run pruefe-abbildungen`.
